# PropLink
A web-based real estate platform that connects property buyers and sellers through verified property listings. Sellers can submit property details and verification documents, while administrators review and approve listings before they become visible to buyers.

## Quick Start (Run with One Command)

You can run the application using any of the following single commands from the project root:

### Option 1: Standard .NET CLI
```bash
dotnet run
```

### Option 2: Windows Command Prompt / Batch
```cmd
run
```
*(or `.\run.bat`)*

### Option 3: PowerShell
```powershell
.\run.ps1
```
*(or `.\run.ps1 -Watch` for hot-reload mode)*

### Option 4: Bash / Linux / WSL / macOS
```bash
./run.sh
```

---
Once started, open your browser and navigate to:
**http://localhost:5019**
